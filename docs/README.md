# Cliffford V2 – Documentation

Living docs. Wird bei jeder relevanten Änderung oder Design-Entscheidung aktualisiert.

## Ordner

| Ordner | Was kommt hier rein? |
|--------|---------------------|
| `architecture/` | Design-Entscheidungen, ADRs, Architektur-Übersichten |
| `agent/` | Agent Loop, Debugging-Guides, Verhaltensdokumentation |
| `changes/` | Changelog, Release Notes, Breaking Changes |
| `tools/` | Dokumentation der verfügbaren Tools (Parameter, Beispiele, Edge Cases) |

## Konvention

- Neue Datei pro Thema (z. B. `architecture/adr-001-pi-ai-only.md`)
- Datum im Frontmatter oder Header, damit man sieht, wann es geschrieben/aktualisiert wurde
- Bei Design-Entscheidungen: Problem → Optionen → Entscheidung → Konsequenzen
